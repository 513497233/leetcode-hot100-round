# Hot100 Round

按「轮」刷 leetcode.cn 热题 100 的 VS Code 插件：同一个账号反复刷，每轮单独统计进度，随机出题只从本轮没做过的题里抽；本地写代码，一键云端测试 / 提交。

> 本插件为个人开发的非官方工具，与力扣（LeetCode）官方无关。它通过 leetcode.cn 网页使用的接口工作，需要你自己粘贴登录 Cookie；接口如有变动可能失效。

## 安装

1. 到 [Releases](https://github.com/513497233/leetcode-hot100-round/releases) 下载最新的 `.vsix` 文件。
2. VS Code 扩展面板右上角 `...` → **从 VSIX 安装…**（Install from VSIX…），选择下载的文件。
3. 安装后执行一次 `Developer: Reload Window`，左侧活动栏会出现 Hot100 图标。

升级时下载新版本的 `.vsix` 重复以上步骤即可，本轮进度会保留。

## 功能

- **本轮进度**：一轮 = 一个开始时间。本轮内有 AC 提交的题算完成，数据来自你账号的提交记录，在浏览器里做的题也会统计进去。
- **设置开始时间**：`Hot100: 设置本轮开始时间`，例如从上周三开始刷就填 `2026-11-04`，会按新时间重新统计。
- **随机出题**：状态栏 `Hot100 第N轮 x/100` 或侧边栏 🔁 按钮，从本轮未完成的题里随机抽一道，在本地打开题解文件（题目右侧 🌐 按钮可在浏览器打开）。
- **手动修改**：侧边栏每道题右侧 ✓ 按钮可切换本轮完成状态，手动修改的题会标注「手动」，优先级高于同步结果。
- **重新开始一轮**：侧边栏 ＋ 按钮，之前的提交不再计入新一轮。
- **本地写题**：点侧边栏题目，在题解目录生成 `{题号}.{slug}.{扩展名}` 文件（如 `1.two-sum.cpp`），旁边显示题面。只有 `@hot100 code=start` / `code=end` 两行之间的代码会提交，之外可以写本地调试代码。
- **云端测试 / 提交**：题解文件上方、编辑器右上角、题面页顶部都有「测试 / 自定义用例测试 / 提交」按钮。结果输出到「Hot100 结果」面板；提交 AC 直接计入本轮。
- **本轮统计**：侧边栏 📈 按钮。已完成 / 剩余、按难度和按类型的剩余数、每道题的本轮提交次数和通过次数。
- **绑定状态**：状态栏悬停可看到账号；未绑定或 Cookie 失效时状态栏前面显示 ⚠，也可执行 `Hot100: 查看绑定状态`。
- **自动同步**：启动时、以及从浏览器切回 VS Code 时（间隔超过 60s）自动同步。

## 使用

1. 浏览器登录 leetcode.cn，开发者工具 → Network → 任一请求 → Request Headers 复制整段 `Cookie`。
2. VS Code 命令面板执行 `Hot100: 绑定 leetcode.cn 账号（Cookie）`，粘贴。Cookie 只保存在本机 VS Code 的 SecretStorage 中，不会上传到别处。
3. 点左侧活动栏的 Hot100 图标查看本轮进度，第一次点题目会让你选语言和题解目录（之后可在面板 `...` 菜单里改）。

## 开发

```bash
npm install
npm test          # 编译 + 单测
npm run package   # 打出 .vsix
```

VS Code 打开本目录按 F5 调试。

## 同步原理

1. `userProgressQuestionList` 拉账号所有题的最后提交时间，筛出本轮开始后有新提交的 Hot100 题。
2. 对这些题用 `submissionList` 倒序翻提交记录，统计本轮内的提交次数、通过次数。
3. 已统计过且之后没有新提交的题不再重复查。第 1 步不可用时退化为逐题统计。
